# Affectiva

> Emotion AI out of the MIT Media Lab, headquartered in Boston. Affectiva's AFFDEX science
> measures emotion, attention and cognitive state from spontaneous facial expressions and
> speech, trained on 17.4M face videos and 8B facial frames from 90 countries. Sold into
> media analytics (ad and entertainment content testing, qualitative research), in-cabin
> automotive driver and occupant monitoring, and academic behavioral research. Acquired by
> Smart Eye AB in 2021; the commercial product line has since been folded into the iMotions
> brand, and www.affectiva.com now 301s its product, solutions and contact pages to
> imotions.com.

Generated by API Evangelist on 2026-09-12. Affectiva serves no llms.txt of its own —
https://www.affectiva.com/llms.txt and https://index.affectiva.com/llms.txt both return 404.

## API

The developer surface is the **Affectiva Facial Coding API**, branded internally as "EaaS"
(Emotion as a Service). Upload video, get frame-by-frame expression and Action Unit metrics
back as JSON or CSV.

- Base URL: https://index.affectiva.com
- Interactive reference (Swagger UI): https://index.affectiva.com/swagger/index.html
- Console sign-in: https://index.affectiva.com/users/sign_in
- Authentication: HTTP Basic. The live API answers
  `WWW-Authenticate: Basic realm="Affectiva Facial Coding API"` and there is no public
  self-service sign-up — /users/sign_up returns 404.
- Contract: 13 Swagger 2.0 documents, 51 operations, served from
  https://index.affectiva.com/swagger/templates/<name>.json

## Contracts

- [Data collection projects](https://index.affectiva.com/swagger/templates/data_collection_projects.json): CRUD on projects.
- [Jobs](https://index.affectiva.com/swagger/templates/jobs.json): submit and read facial-coding analysis jobs.
- [Entries](https://index.affectiva.com/swagger/templates/entries.json): media units and their annotations; annotation search.
- [Representations](https://index.affectiva.com/swagger/templates/representations.json): derived renderings of an entry's media.
- [Representation storages](https://index.affectiva.com/swagger/templates/representation_storages.json): where a representation is stored.
- [Event configs](https://index.affectiva.com/swagger/templates/event_configs.json) / [Event instances](https://index.affectiva.com/swagger/templates/event_instances.json): per-project event definitions and occurrences.
- [Frame sampling jobs](https://index.affectiva.com/swagger/templates/frame_sampling_jobs.json): cut a video into frames or segments.
- [Video frames](https://index.affectiva.com/swagger/templates/video_frames.json) / [Video segments](https://index.affectiva.com/swagger/templates/video_segments.json).
- [Labeling jobs](https://index.affectiva.com/swagger/templates/labeling_jobs.json) / [Labeling tasks](https://index.affectiva.com/swagger/templates/labeling_tasks.json) / [Labeling job annotations](https://index.affectiva.com/swagger/templates/labeling_job_annotations.json): the human-labeling pipeline.

## What Affectiva does not publish

Recorded so an agent does not go looking: no OpenAPI 3.x (the contracts are Swagger 2.0), no
GraphQL, no MCP server, no A2A agent card, no AsyncAPI or webhook catalog, no security.txt,
no /.well-known documents of any kind, no status page (status.affectiva.com does not
resolve), no changelog, no CLI, no public pricing or plans, no documented rate limits, no
idempotency mechanism, no reversal or undo operation for any of its 33 write operations, and
no pagination on any collection endpoint. The former documentation hub
knowledge.affectiva.com now returns a readme.io "Not Yet Active" placeholder, and both
developer.affectiva.com and auto.affectiva.com redirect to an Atlassian Confluence login.
